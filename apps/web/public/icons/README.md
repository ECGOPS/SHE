# PWA icons

Place the following icons in this directory before building the PWA:

| File | Size | Purpose |
| ---- | ---- | ------- |
| `icon-192.png` | 192×192 | Standard launcher icon |
| `icon-512.png` | 512×512 | Splash & high-DPI launcher |
| `icon-512-maskable.png` | 512×512 | Adaptive (maskable) Android icon |

Recommended brand colours:

- Primary: `#0B5394`
- Background: `#0B1A2B`
- Accent: `#FBB040`

Generate with any icon tool (e.g. [pwa-asset-generator](https://github.com/elegantapp/pwa-asset-generator))
or your design suite. Keep transparent backgrounds for the maskable variant only when using a safe area.
